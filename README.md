# job-portal-project
Basic UI - using Reactjs and full backend setup using - java springboot and Using SQL for Database

Job Portal Application
A Full Stack Job Portal built using Java Spring Boot, ReactJS, and MySQL.

Features:
Add Jobs
View Jobs
Delete Jobs
Apply for Jobs
Store Applicant Details
View Applicants per Job
Tech Stack

Frontend:
ReactJS
Axios
React Router DOM

Backend:
Java
Spring Boot
Spring Data JPA
REST APIs

Database:
MySQL

API Endpoints
GET /api/jobs
POST /api/jobs
DELETE /api/jobs/{id}
POST /api/applications/{jobId}
GET /api/applications/job/{jobId}

Installation

Backend
mvn spring-boot:run

Frontend
npm install
npm run dev

Future Improvements
JWT Authentication
Admin/User Roles
Improve UI using ReactJS
